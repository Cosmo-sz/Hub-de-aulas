O que é o Grid?

O CSS Grid é um modelo de layout do CSS que permite organizar elementos em linhas e colunas, facilitando a criação de estruturas para páginas e interfaces.

Com ele, podemos:

  • Organizar elementos em linhas e colunas;
  • Controlar o tamanho das linhas e colunas;
  • Definir espaços entre os elementos;
  • Posicionar elementos em áreas específicas do layout.

Exemplo Visual do Grid

No exemplo abaixo, os elementos estão organizados em três colunas de mesmo tamanho.

.container {
  display: grid;

}

Principais Propriedades

1. display: grid

Ativa o CSS Grid no contêiner, permitindo organizar os elementos em linhas e colunas.

2. grid-template-columns

Define a quantidade e o tamanho das colunas do Grid.

3. grid-template-rows

Define a quantidade e o tamanho das linhas do Grid.

4. gap

Define o espaçamento entre as linhas e as colunas.

5. justify-items

Controla o alinhamento dos elementos dentro de suas células no eixo horizontal.

6. align-items

Controla o alinhamento dos elementos dentro de suas células no eixo vertical.

Exemplo Prático

O Grid permite criar colunas com proporções diferentes. No exemplo abaixo, a primeira coluna ocupa o dobro do espaço da segunda: 

.container {
  display: grid;
  grid-template-columns: 2fr 1fr;
  gap: 15px;
}

A propriedade grid-template-columns: 2fr 1fr; divide o espaço disponível em três partes: duas para a primeira coluna e uma para a segunda.

Dica Extra

O CSS Grid é especialmente útil para criar layouts de páginas, galerias de imagens, painéis de controle e interfaces divididas em áreas. 

.layout {
  display: grid;
  grid-template-columns: 200px 1fr;
  gap: 20px;
}

Nesse exemplo, a primeira coluna tem 200 pixels de largura, enquanto a segunda ocupa o espaço restante disponível.
