O que é o Flexbox?

O Flexbox é um modelo de layout do CSS que facilita a organização, o alinhamento e a distribuição dos elementos dentro de um contêiner.

Com ele, podemos:

  • Organizar elementos em linhas ou colunas;
  • Alinhar elementos horizontal e verticalmente;
  • Distribuir o espaço entre os elementos;
  • Permitir que os elementos quebrem para outra linha.

Principais Propriedades

1. display: flex

Ativa o Flexbox no contêiner, permitindo organizar os elementos filhos.

2. flex-direction

Define a direção dos elementos. Pode usar row para linha ou column para coluna.

3. justify-content

Distribui os elementos ao longo do eixo principal, usando valores como center, space-between e space-around.

4. align-items

Controla o alinhamento dos elementos no eixo transversal, como em center e flex-start.

5. flex-wrap

Define se os elementos podem passar para outra linha quando não há espaço suficiente.

6. gap

Define o espaçamento entre os elementos, sem precisar adicionar margens individuais.

Exemplo Prático

Para organizar três caixas verticalmente, basta alterar a direção do contêiner: 

.container{
    display: flex;
    flex-direction: column;
    align-items: center;
    gap: 15px;
}

A propriedade flex-direction: column; coloca os elementos um abaixo do outro.

Dica Extra

O Flexbox é especialmente útil para menus, barras de navegação, botões, cartões e alinhamento de elementos em uma interface. 

.menu{
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
 }
