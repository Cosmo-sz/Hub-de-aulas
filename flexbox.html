O que é o Flexbox?

O Flexbox é um modelo de layout do CSS que facilita a organização, o alinhamento e a distribuição dos elementos dentro de um contêiner.

Com ele, podemos:

  • Organizar elementos em linhas ou colunas;
  • Alinhar elementos horizontal e verticalmente;
  • Distribuir o espaço entre os elementos;
  • Permitir que os elementos quebrem para outra linha.
